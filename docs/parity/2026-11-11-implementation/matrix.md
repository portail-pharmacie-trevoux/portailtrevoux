# Matrice après préparation des correctifs

« Validé localement » signifie code exécuté sur fixtures/mocks ou PostgreSQL jetable.
Aucune ligne ne signifie « déployé et validé sur Scalingo ». Les données réelles
restent **non inventoriées ici** ; aucune reprise n'a eu lieu.
